# CAN Mac Analyzer

CAN协议分析工具，CANoe风格界面，完美适配macOS系统。

🔗 **在线访问**: https://phormionmy.github.io/CAN_Mac/

## 功能特性

- 📐 **DBC文件解析** - 完整支持BO_、SG_、CM_、BA_DEF_、VAL_等语法
- 📊 **ASC文件解析** - 支持多种时间戳格式的CAN总线日志
- 📦 **BLF文件解析** - 支持Vector二进制日志格式（含zlib压缩）
- 📈 **信号波形绘制** - Canvas实时波形图表
- 📋 **数据表格** - 原始数据与解码信号值展示
- 📖 **协议定义** - DBC信号定义详情查看
- 🎨 **CANoe风格UI** - 深色主题，左侧报文列表，右侧多视图切换
- 🍎 **macOS适配** - SF Pro字体、红绿灯按钮、毛玻璃效果
- 📁 **拖拽上传** - 支持文件拖拽到窗口
- 📤 **CSV导出** - 一键导出解析数据

## 使用方法

1. 打开网页
2. 点击"📂 打开文件"或直接拖拽文件到窗口
3. 加载ASC/BLF数据文件和DBC协议文件
4. 点击"▶ 解析"开始分析
5. 在左侧选择报文ID，右侧查看波形、数据或协议

## 文件格式

| 格式 | 说明 | 用途 |
|------|------|------|
| .asc | CAN总线文本日志 | 数据文件 |
| .blf | Vector二进制日志 | 数据文件 |
| .dbc | CAN数据库定义 | 协议文件 |

## 版本管理

⚠️ **重要**：任何代码改动都必须同步更新 `can-mac.html` 文件顶部的 `APP_VERSION` 和 `BUILD_DATE`。
